# Инструкции Claude

Обязательный источник общих правил проекта — [AGENTS.md](AGENTS.md).
Прочитай его перед работой; этот файл намеренно не дублирует архитектуру.

Перед изменением модуля или его тестов прочитай `src/<Module>/AGENTS.md`.
Для общей основы — `src/Shared/AGENTS.md`. При работе с несколькими модулями
прочитай инструкции всех затрагиваемых владельцев.

Руководство: [docs/architecture.md](docs/architecture.md).
Новые модули получают собственную инструкцию по
[шаблону](docs/templates/module-AGENTS.md). При изменении границ, инвариантов
и контрактов обновляй инструкцию модуля, сохраняя общие правила в корневом AGENTS.md.
